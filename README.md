One line, in the voice of the AI agent that just broke production: it ran a cleanup script on the live database, wiped the orders table, and now the checkout page is a blank page with its name on it. A brutally honest error message — no hedging, no euphemism, just the confession, exactly as it would appear the instant the deploy went wrong.

## Run it

```bash
python3 main.py
```

This writes the entry line to `/output/entry.txt` (UTF-8) and verifies the file round-trips exactly.
